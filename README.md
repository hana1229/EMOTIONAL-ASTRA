# EMOTIONAL ATLAS · FINAL v11

서울과학기술대학교 시각디자인 대학원 중간평가용 인터랙티브 웹 프로토타입. GitHub Pages 정적 호스팅에 맞춰 구성했습니다.

## 기존 사이트를 전체 교체하기

1. `EMOTIONAL_ATLAS_FINAL_v11.zip`을 내려받아 압축을 풉니다.
2. **압축 해제된 `EMOTIONAL_ATLAS_FINAL_v11` 폴더 안의 모든 파일과 `icons` 폴더를 함께** GitHub `SOOM-PYO` 저장소의 **루트**에 업로드해 기존 파일을 교체합니다.
3. `Commit changes` 후 GitHub Pages 웹사이트에서 `Cmd + Shift + R`로 새로고침합니다.
4. **GitHub 저장소 자체를 삭제하거나 저장소 주소를 바꾸지 마세요.** 사이트 주소가 달라지면 브라우저에 저장된 과거 감정 기록에 접근할 수 없을 수 있습니다. 업데이트 전 사이트의 `기록 백업` 기능으로 JSON 백업을 권장합니다.

```text
SOOM-PYO/
├── index.html
├── style.css
├── app.js
├── my.js
├── organism.js
├── jar.js               ← 새 파일, 구슬 드래그 물리 상호작용
├── storage.js
├── world.js
├── wvs-summary.json
├── world.geojson
├── icons/               ← 새 폴더, 10개 감정 아이콘 PNG
│   ├── joy.png
│   ├── calm.png
│   ├── excitement.png
│   ├── nostalgia.png
│   ├── sadness.png
│   ├── anxiety.png
│   ├── anger.png
│   ├── lethargy.png
│   ├── anticipation.png
│   └── loneliness.png
└── README.md
```

**중요**: `icons` 폴더를 함께 올리지 않으면 캘린더/아카이브 아이콘이 보이지 않습니다. 폴더의 이름을 그대로 유지해야 합니다.

## FINAL v9 구현

- **감정 아이콘 10종**: 기쁨(꽃), 평온(민트 오브), 설렘(별), 그리움(초승달), 슬픔(물방울), 불안(소용돌이), 분노(코랄 버스트), 무기력(구름), 기대(혜성 별), 외로움(링 오브). 이전에 제작한 디자인을 투명 PNG로 최적화해 포함했습니다.
- **감정 캘린더**: 각 날짜의 대표 감정 아이콘과 기록에서 선택했던 QUALI 색상 사용. 기록된 날짜는 선택한 색상으로 칸을 채우고 감정 아이콘은 칸의 80%를 차지하도록 배치했습니다. 재질은 오른쪽 하단의 작은 아이콘으로 유지합니다. 하루 여러 기록이 있는 경우 감정 강도의 합으로 대표 감정을 선택하며 수동 대표 지정도 유지합니다.
- **나만의 감정 아카이브**: 기존 작은 구슬 대신 감정 아이콘 썸네일을 사용합니다.
- **30일 유리병**: 30일 동안 기록된 날짜별 구슬을 드래그해 직접 움직일 수 있습니다. 주변 구슬과 가볍게 충돌하고 놓으면 크기/밀도로 정해진 층으로 부드럽게 돌아갑니다. 시각적 놀이 기능으로서 구슬의 실제 위치가 기록을 수정하지는 않습니다. 모바일은 터치 드래그를 지원합니다.
- **기존 v8의 WORLD EMOTION 유지**: 3D 지구본 국가 선택, 국가별 조사연도 흐름, 만족도·매우 행복 중첩 면 그래프, 국가 비교, 글로벌 차수별 전체 개요, 분포 및 행복감 × 만족도 4구간 기본 히트맵. WVS 요약 데이터는 변경하지 않았습니다.
- **MY EMOTION 유지**: 감정 일기, 감정 제안(로컬 키워드 기반), QUALI 3D/2D, 재질, 크기, 표면 결, 투명도, 저장·수정, 통계 및 JSON 백업/복원.

## 동작 및 데이터 주의

- 사이트는 GitHub Pages 또는 `python3 -m http.server` 같은 웹서버에서 실행해야 하며, `index.html`을 로컬에서 더블클릭하는 방식은 데이터 파일 로딩이 차단될 수 있습니다.
- 3D QUALI 및 지구본은 외부 CDN을 이용합니다. 인터넷이 차단되어 있으면 3D 대신 대체 화면이 나올 수 있습니다.
- WVS는 실제 조사연도별 서로 다른 응답자 표본의 조사값입니다. 시계열 그래프에서 연결선은 중간 연도의 실측값을 의미하지 않습니다. 글로벌 요약은 참여국의 동일 비중 평균이며 인구 가중 전 세계 평균이 아닙니다.
- 데이터 원본 CSV 파일은 배포 ZIP에 포함하지 않습니다.
- 기존 기록은 해당 브라우저/사이트 주소의 로컬 저장소에 보관됩니다. 이 ZIP에는 개인 기록이 포함되지 않습니다.

## 검증

JavaScript 구문 검사, ZIP 무결성 검사, 아이콘 PNG 10종 참조 및 이미지 투명도, 캘린더 80% 크기/선택 색 배경, 그리고 유리병의 마우스 드래그 이벤트를 분리된 Chromium 브라우저 테스트로 확인했습니다. 완성된 웹페이지의 전체 통합 실행은 실행 환경의 로컬 서버 접근 제한으로 검증되지 않았으므로 실제 GitHub Pages 배포 후 최종 화면을 확인해주세요.


## v10 UI 정리
- WORLD EMOTION의 나라별 요약 카드를 '시간의 흐름으로 읽는 감정 지표' 제목 바로 아래로 옮겼습니다.
- 데스크톱 넓은 화면에서 최대 3개 국가가 한 줄에 배치됩니다. 중간 화면은 2열, 모바일은 1열입니다.
- 국가 2개 이상 선택 시 요약 카드를 누르면 해당 국가의 조사 시점, 그래프, 히트맵, 연령별 통계, 해설만 표시됩니다.
- 다른 국가 카드를 누르면 해당 국가로 전환하고, 선택된 카드를 다시 누르거나 '전체 국가 비교 보기'를 누르면 전체 비교가 복원됩니다. 선택한 국가 목록 자체는 삭제되지 않습니다.


## FINAL v11 · WORLD EMOTION 조사 차수별 흐름 개선

- 대한민국, 가나, 나이지리아 등 여러 국가를 선택할 때 **각 국가의 대표 색을 유지**합니다. 한 국가의 만족도와 매우 행복 응답률은 같은 색 계열을 씁니다.
- 삶의 만족도는 또렷한 실선과 연한 배경면으로, 매우 행복 응답률은 같은 색 계열의 **반투명 유리형 그래프 면**으로 나타냅니다. 좌측 축(0~10점), 우측 축(0~100%)은 유지합니다.
- 국가별 일부 조사 차수가 없거나 선택한 지표가 누락된 경우, 관측 구간 사이를 **대표 색 → 회색 → 대표 색**의 그라데이션 안내선으로 연결합니다. 해당 구간은 실측 데이터가 아니라는 점을 그래프 아래에 명시합니다. 미관을 위한 곡선에는 별도의 데이터 점을 만들지 않습니다.
- 기존 QUALI, 감정 캘린더, 감정 아카이브, 유리병 인터랙션, 국가별 상세/전 세계 개요 기능, WVS 데이터는 변경하지 않았습니다.
- 검증: JavaScript 문법 검사, 실제 포함된 WVS 요약 데이터를 이용한 **격리된 차트 브라우저 테스트**(3개국 색상·유리면·회색 공백 확인), 기존 데이터/이미지 파일의 바이트 일치 확인을 수행했습니다. 전체 웹페이지의 통합 배포 테스트는 별도로 필요합니다.

## v12 · 단일국가 통계 및 감정 제안 수정

- **단일국가 (또는 여러 국가 카드 중 한 국가를 클릭한 상세 보기)**: 최초에는 각 조사연도를 나누어 모든 시점의 행복감 분포, 삶의 만족도 분포, 4/10구간 관계 행렬 및 연령별 삶의 만족도를 보여줍니다. 기존 시계열 그래프는 그대로 유지됩니다.
- `모든 차수의 상세 지표 보기`로 전체 이력으로 돌아갈 수 있으며, 특정 조사연도 점이나 조사 이력표의 연도를 누르면 해당 시점의 상세 분석만 표시합니다.
- 모든 국가를 비교하는 모드에서는 기존대로 선택된 차수의 분포와 지표를 국가별로 나란히 비교합니다.
- 공개되지 않거나 조사하지 않은 문항/연도에는 `미조사 또는 공개 가능한 표본 부족`이라고 표시하고 수치를 만들지 않습니다. 이력의 지표별 제공 여부는 별도 요약표에서 확인할 수 있습니다.
- 감정 제안은 **로컬 문구 기반 추정**입니다. 알 수 없는 문장이면 무조건 `평온`을 반환하던 기존 오류를 고쳐, 자동 선택을 하지 않고 직접 감정을 선택하도록 안내합니다. 일부 어휘를 보완하고 긍정 표현의 기본적인 부정형을 피하도록 하였습니다. 자연어의 모든 뉘앙스를 읽는 실제 AI는 아닙니다.
- 데이터 원본의 모든 설문을 합쳐 하나의 값으로 계산하지 않습니다. 각 시점의 개별 조사 수치만 사용하며, 기본 연령 선택은 **18세 이상**입니다. `전체` 버튼으로 전체 연령 데이터가 있는 시점은 별도로 볼 수 있습니다.
