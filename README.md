# EMOTIONAL ATLAS v6 | GitHub Pages 전체 교체본

2026년 10월 수정본. **v6: WORLD EMOTION에 「전 세계 한눈에 보기」 버튼을 추가**했습니다. 국가 선택 없이 WVS 조사 1~7차에서 하나를 고르면 해당 차수의 모든 참여국을 한 화면에서 비교합니다. 기존 v5 디자인과 MY EMOTION은 유지했습니다.

 MY EMOTION의 **QUALI 선택 UI 미니멀화**, 몽글한 **SMOKE 안개 유기체**, WORLD EMOTION의 **실제 조사연도 타임라인 및 파스텔 그래프 카드**를 반영했습니다.

## GitHub 업로드

1. `EMOTIONAL_ATLAS_전체교체_v6.zip` 파일의 압축을 풉니다.
2. 압축 해제한 `EMOTIONAL_ATLAS_전체교체_v6` 폴더 **안쪽의 파일 10개**를 선택합니다.
3. GitHub `SOOM-PYO` 저장소의 **main 브랜치 최상위(루트)**에 모두 업로드합니다. 파일이 중복되면 기존 파일을 교체합니다.
4. **Commit changes** 후 GitHub Pages URL을 열어 **Cmd + Shift + R**로 새로고침합니다.

폴더 구조(모두 최상위 파일):


## v6 변경 사항

- **전 세계 한눈에 보기** 버튼으로 글로벌 스냅샷 모드 전환. 국가를 미리 선택할 필요가 없습니다.
- 조사 차수 1~7차 중 하나를 선택하면 **그 차수에 실제 참여한 국가 전체**를 국가별 도트 그래프, 정렬 가능한 전체 국가 목록, 참여국 요약 지표, 행복감 분포로 확인합니다.
- 국가별 만족도 평균 및 행복감 비율은 해당 국가의 WVS 집계값입니다. 글로벌 한 줄 요약값은 **값이 존재하는 참여국들을 동일 비중으로 평균**한 수치입니다. 인구 가중 세계 평균이나 전 인류 대표 통계가 아닙니다.
- 서로 다른 국가에서 조사연도가 다를 수 있으므로, 차수 기준 비교임을 표시합니다.
- 글로벌 모드에서 국가 항목을 클릭하면 개별 국가 상세 모드로 이동합니다. 이전 개인 분석 선택은 모드 간 되돌릴 수 있습니다.

## v5 변경 사항

- WORLD EMOTION: 실제 WVS 조사 연도 기반 타임라인(국가별 제공되는 시점만 표시), 클릭 시 해당 차수 상세 통계 전환, 선택적 2~3개국 시계열 겹쳐보기, 파스텔/화이트 에디토리얼 차트 카드 및 곡선 없이 관측점 연결하는 흐름 그래프.
- MY EMOTION: 큰 장식 카드 대신 작고 기능적인 QUALI/개별 감정 선택 칩. 각 칩은 해당 재질 아이콘과 현재 선택 색을 나타냅니다.
- SMOKE: 3D 안개형 유기체를 위한 다층 반투명 프로시저럴 셰이더, 천천히 움직이는 구형 안개층. 투명도와 표면 결 설정에 반응합니다. WebGL 불가 시 2D 재질 아이콘으로 대체됩니다.
- WVS 원본 개별 응답 CSV는 포함하지 않으며 기존 요약 데이터 파일을 사용합니다.

## 실행/주의

GitHub Pages 배포 또는 `python3 -m http.server 8000` 등 로컬 웹서버 환경에서 열어야 합니다. 브라우저에서 직접 `index.html`을 더블클릭하면 데이터 fetch가 제한될 수 있습니다. Three.js / Globe.gl 은 외부 CDN을 불러오며 네트워크 접근이 안 되는 경우 2D 대체 모드가 표시될 수 있습니다.

현재 버전은 JavaScript 구문 검사, HTML 참조 파일 검사 및 WVS JSON 구조 검사를 거쳤습니다. 이 제작 환경에서는 Chromium의 로컬 주소 접근이 정책상 차단되어 **실제 브라우저 3D 렌더링 및 클릭 연동 전체 검증은 완료하지 못했습니다.** 사이트 업로드 후 화면 캡처와 기능 점검으로 최종 확인해야 합니다.
